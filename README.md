# kthari.com

Official site for *The Seven Kingdoms of K'Thari* by Njintieuh Sieni.

- **Edit the site:** https://app.pagescms.org → sign in with GitHub → open this repo. Change text, upload pictures, add News posts, then **Save**. The live site updates in about a minute.
- **Hosting:** Cloudflare Pages (build command `npm run build`, output folder `_site`).
- **Text tips:** a blank line starts a new paragraph; `*word*` makes it italic.
